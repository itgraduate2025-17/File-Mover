File Mover App
Description

This app moves all files from a source folder to a destination folder using Python and Gradio.
It’s simple, easy to use, and shows which files were moved.

Features

Move any type of file (.txt, .jpg, .pdf, etc.)

Automatically creates the destination folder if it doesn’t exist

Shows a list of moved files in the app

Requirements

Python 3.x

Gradio (pip install gradio)

How to Use

Run the Python script:

python file_mover_app.py


Enter the source folder path.

Enter the destination folder path.

Click Move Files.

Check the result box to see all moved files.

Notes

Only files are moved, not empty folders.

You can modify the code to move folders recursively if needed.
