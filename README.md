# File Mover App

This app moves all files from a source folder to a destination folder using Python and Gradio.  
It is simple, easy to use, and shows which files were moved.

## Features
- Move any type of file (.txt, .jpg, .pdf, etc.)  
- Automatically creates the destination folder if it doesn’t exist  
- Shows a list of moved files in the app

## Requirements
- Python 3.x  
- Gradio (install using `!pip install gradio` in Google Colab)
